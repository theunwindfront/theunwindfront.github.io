# theunwindfront.github.io

Personal site and blog for Sagar Pansuriya — static HTML, no build step, no
Jekyll. Deployed by GitHub Pages from `main`.

## Commits

Do **not** add Claude attribution to commits or pull requests. Specifically, no
`Co-Authored-By: Claude …` trailer and no `🤖 Generated with Claude Code` line.

Commits should be authored solely by the repo owner so they count toward the
GitHub contribution graph — a `Co-Authored-By` trailer splits credit and can
suppress it.
